# Kapitel 9 – ArrayList

## 1. Introduktion

Session 9 introducerer `ArrayList`.

`ArrayList` er en samlingsklasse, der dynamisk kan gemme objekter.

Fokus er på:

- `ArrayList`
- dynamiske samlinger
- samlinger af objekter
- wrapper-klasser
- tilføjelse og fjernelse af elementer
- konvertering mellem arrays og samlinger

`ArrayList` løser mange af begrænsningerne ved arrays.

---

## 2. Hvorfor ArrayList?

Arrays har en fast størrelse.

Eksempel:

```java
private int[] grades;
```

Når arrayet er fyldt, skal der manuelt oprettes et større array.

`ArrayList` håndterer automatisk ændring af størrelsen.

Eksempel:

```java
private ArrayList<Integer> grades;
```

Fordele:

- dynamisk størrelse
- enklere kode
- lettere indsættelse og fjernelse af elementer

---

## 3. Import af ArrayList

`ArrayList` er en del af Java Collections Framework.

Eksempel:

```java
import java.util.ArrayList;
```

Import-sætningen er nødvendig, før klassen kan bruges.

---

## 4. Oprettelse af en ArrayList

Eksempel:

```java
ArrayList<Integer> grades;
```

Samlingsobjektet skal oprettes.

Eksempel:

```java
grades = new ArrayList<Integer>();
```

Et typisk mønster:

```java
private ArrayList<Integer> grades;

public GradeList()
{
  grades = new ArrayList<Integer>();
}
```

---

## 5. Generiske typer

`ArrayList` gemmer objekter af én bestemt type.

Eksempel:

```java
ArrayList<String>
ArrayList<Person>
ArrayList<Integer>
```

Typen mellem `< >` angiver, hvilke objekter der må gemmes.

Dette forbedrer typesikkerheden.

---

## 6. Wrapper-klasser

`ArrayList` kan kun gemme objekter – ikke primitive datatyper.

Primitive datatyper anvender derfor wrapper-klasser.

Eksempler:

| Primitiv datatype | Wrapper-klasse |
|---|---|
| `int` | `Integer` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

Eksempel:

```java
ArrayList<Integer> grades;
```

i stedet for:

```java
ArrayList<int>
```

som er ugyldigt.

---

## 7. Tilføjelse af elementer

Elementer tilføjes med `add()`.

Eksempel:

```java
grades.add(12);
grades.add(7);
grades.add(10);
```

I dette eksempel bliver `int`-værdierne 12, 7 og 10, som sendes som argumenter til metoden `add()`, automatisk konverteret til `Integer`-objekter. Dette kaldes **autoboxing**.

Samlingen vokser automatisk, når det er nødvendigt.

Der er ikke behov for manuel ændring af størrelsen.

---

## 8. Adgang til elementer

Elementer hentes med `get()`.

Eksempel:

```java
int grade = grades.get(0);
```

Indekser starter stadig ved `0`.

Eksempel:

```text
Indeks:  0   1   2
Værdi:  12   7  10
```

---

## 9. Udskiftning af elementer

Elementer kan udskiftes med `set()`.

Eksempel:

```java
grades.set(1, 4);
```

Elementet ved indeks `1` bliver nu `4`.

---

## 10. Fjernelse af elementer

Elementer kan fjernes med `remove()`.

Eksempel:

```java
grades.remove(1);
```

Når et element fjernes, flyttes de efterfølgende elementer automatisk.

Det er enklere end manuel flytning i et array.

---

## 11. Samlingens størrelse

`ArrayList` holder selv styr på sin størrelse.

Eksempel:

```java
grades.size()
```

Vigtigt:

- `size()` er en metode
- arrays bruger `length`

Eksempel:

```java
grades.size()
```

i forhold til:

```java
array.length
```

---

## 12. Gennemløb af en ArrayList

Samlinger gennemløbes ofte med løkker.

### Indeksbaseret `for`-løkke

Eksempel:

```java
int sum = 0;
for (int i = 0; i < grades.size(); i++)
{
  sum += grades.get(i);
}
```

### Enhanced `for`-løkke

Eksempel:

```java
int sum = 0;
for (int grade : grades)
{
  sum += grade;
}
```

Efter Session 8 og 9:

- brug enhanced `for`-løkker, når indekset ikke er nødvendigt
- brug indeksbaserede løkker, når indekset er nødvendigt

---

## 13. Samlinger af objekter

`ArrayList` er især velegnet til at gemme objekter.

Eksempel:

```java
private ArrayList<Person> persons;
```

Objekter kan tilføjes:

```java
persons.add(new Person("Bob"));
persons.add(new Person("Ada"));
```

Samlingen gemmer referencer til objekterne.

---

## 14. Søgning i samlinger

Løkker kan bruges til at søge i samlinger.

Eksempel:

```java
public Person findPerson(String name)
{
  for (Person person : persons)
  {
    if (person.getName().equals(name))
    {
      return person;
    }
  }

  return null;
}
```

Samlinger gennemløbes ofte ved søgning.

---

## 15. Fjernelse af objekter

Objekter kan fjernes direkte.

Eksempel:

```java
persons.remove(person);
```

Eller ved indeks:

```java
persons.remove(0);
```

Samlingen organiserer automatisk elementerne efter fjernelsen.

---

## 16. ArrayList og responsibility

Samlingen bør normalt være privat.

Eksempel:

```java
private ArrayList<Person> persons;
```

Andre klasser bør ikke manipulere samlingen direkte.

Godt design:

```java
personList.addPerson(person)
```

i stedet for at eksponere den interne samling.

Klassen bør have responsibility for:

- tilføjelse
- fjernelse
- søgning
- validering

---

## 17. toArray()

En `ArrayList` kan konverteres til et array.

Eksempel:

```java
Person[] array = persons.toArray(new Person[0]);
```

Dette opretter et array med samlingens elementer.

Session 9 introducerer enkel konvertering mellem samlinger og arrays.

---

## 18. Tomme samlinger

Samlinger kan være tomme.

Eksempel:

```java
if (persons.isEmpty())
{
  // ingen personer gemt
}
```

Eksempel:

```java
persons.size() == 0
```

Begge løsninger kan anvendes.

---

## 19. ArrayList kontra arrays

### Arrays

Fordele:

- enkle
- strukturer med fast størrelse
- direkte lagring

Ulemper:

- fast capacity
- manuel ændring af størrelse
- manuel flytning af elementer

### ArrayList

Fordele:

- dynamisk størrelse
- automatisk ændring af størrelse
- lettere indsættelse og fjernelse

Ulemper:

- lidt større overhead
- kan kun gemme objekter

Efter Session 9:

- foretræk `ArrayList`, når størrelsen ændrer sig dynamisk
- brug arrays, når en fast størrelse er tilsigtet

---

## 20. Test af samlingsklasser

Samlingers behavior bør testes grundigt.

Eksempel:

```java
@Test void addPerson()
{
  PersonList list = new PersonList();
  Person person = new Person("Bob");

  list.addPerson(person);

  assertEquals(1, list.size());
}
```

Vigtige testtilfælde omfatter:

- tilføjelse af elementer
- fjernelse af elementer
- søgning
- tomme samlinger
- grænseindekser

---

## 21. Typiske begynderfejl

Almindelige fejl:

1. At glemme at oprette samlingen med `new`.
2. At bruge primitive datatyper i stedet for wrapper-klasser.
3. At forveksle `size()` og `length`.
4. At tilgå ugyldige indekser.
5. At eksponere den interne samling direkte.
6. At glemme, at samlinger gemmer referencer.
7. At bruge indeksbaserede løkker, når en enhanced `for`-løkke er enklere.

---

- Hvorfor er `ArrayList` nyttig?
- Hvorfor bruger `ArrayList` wrapper-klasser?
- Hvad er forskellen mellem arrays og `ArrayList`?
- Hvorfor bør samlinger normalt være private?
- Hvornår er en enhanced `for`-løkke passende?

---

## Opsummering

Session 9 introducerer dynamiske samlinger ved hjælp af `ArrayList`.

Vigtige idéer omfatter:

- `ArrayList` ændrer automatisk størrelse
- samlinger gemmer objekter og referencer
- wrapper-klasser repræsenterer primitive værdier
- samlinger understøtter effektiv tilføjelse, fjernelse og søgning
- enhanced `for`-løkker gør gennemløb enklere
- `ArrayList` er ofte et bedre valg end arrays, når antallet af elementer varierer

`ArrayList` er den foretrukne samlingsklasse i Java, når størrelsen ikke er kendt på forhånd.
