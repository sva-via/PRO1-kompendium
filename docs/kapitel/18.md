## 2. Genopfriskning af GUI-strukturen

Anbefalet GUI-struktur:

```text
FXML-filer
↓

ViewControllers
↓

ViewHandler
↓

Model Interface
↓

Model
```

Responsibilities holdes adskilt.

FXML:

```text
Layout
```

ViewController:

```text
Interaktion
```

Model:

```text
Forretningsansvar
```

Et godt GUI-design bygger på adskillelse af responsibility.

---

## 3. Strukturen af en ViewController

Hvert vindue bør have:

- én FXML-fil
- én ViewController

Eksempel:

```text
LoginView.fxml
↓
LoginViewController
```

En ViewController indeholder typisk:

- FXML-variabler
- hændelsesmetoder
- reference til modellen
- reference til ViewHandler
- reference til rodnoden

Eksempel:

```java
private Model model;

private ViewHandler viewHandler;

private Region root;
```

Responsibility forbliver lokal.

---

## 4. init-metoden

ViewControllers bruger en initialiseringsmetode.

Eksempel:

```java
public void init(
    ViewHandler viewHandler,
    Model model,
    Region root)
{
  this.model = model;
  this.viewHandler = viewHandler;
  this.root = root;
}
```

Formål:

- forbinde ViewHandler
- forbinde modellen
- forbinde rodnoden

FXML opretter kontrolelementerne.

Applikationen forbinder derefter de forskellige responsibilities.


GUI'ens tilstand bør forblive konsistent.


---

## 7. Eksempel på ViewState

Eksempel:

```java
public class ViewState
{
  private int sharedValue1;

  private String sharedValue2;

  public ViewState()
  {
    sharedValue1 = -1;
    sharedValue2 = null;
  }

  public void setSharedValue1(
      int value)
  {
    sharedValue1 = value;
  }

  public int getSharedValue1()
  {
    return sharedValue1;
  }
}
```

Én ViewController:

```text
Gemmer data
```

En anden ViewController:

```text
Læser data
```

Responsibilities holdes adskilt.

```java
      e.getMessage());

```

## 18. Typiske begynderfejl

Almindelige fejl:

1. At placere forretningslogik i ViewController.
2. At dele data direkte mellem controllere.
3. At glemme `reset()`.
4. At lade én controller blive for stor.
5. At ignorere ViewState.
6. At udskifte hele scener unødvendigt.
7. At bryde adskillelsen af responsibility.
