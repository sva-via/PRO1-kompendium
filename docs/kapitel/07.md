# Kapitel 7 – Arrays

## 1. Introduktion

Session 7 introducerer arrays.

Arrays bruges til at gemme samlinger af værdier.

Fokus er på:

- arrays
- samlinger med fast størrelse
- indekser
- capacity (kapacitet) og size (størrelse)
- lagring af flere værdier
- arrays med primitive værdier og objekter

Arrays er den første samlingsstruktur, der introduceres i kurset.

---

## 2. Hvorfor arrays?

Nogle gange skal en klasse gemme mange værdier.

Eksempler:

- karakterer
- navne
- temperaturer
- opgaver

Det er ikke skalerbart at bruge mange separate variabler.

Mindre god løsning:

```java
private int grade1;
private int grade2;
private int grade3;
private int grade4;
```

Bedre løsning:

```java
private int[] grades;
```

Et array gemmer mange værdier af samme type.

---

## 3. Arrays er objekter

Et array er et objekt.

En variabel gemmer en reference til arrayet.

Eksempel:

```java
private int[] grades;
```

I starten:

```java
grades == null
```

Array-objektet skal oprettes, før det kan bruges.

---

## 4. Oprettelse af arrays

Arrays oprettes med `new`.

Eksempel:

```java
grades = new int[4];
```

Dette opretter et array med:

- capacity 4
- indekser fra `0` til `3`

Arrays har altid en fast længde.

---

## 5. Array-indekser

Array-indekser starter ved `0`.

Eksempel:

```text
Indeks:  0   1   2   3
Værdi:  12   7  10   4
```

Adgang til elementer:

```java
grades[0]
grades[1]
```

Indekser skal altid ligge inden for arrayets grænser.

---

## 6. Capacity og size

Session 7 introducerer en vigtig forskel.

### Capacity

Capacity er arrayets længde.

Eksempel:

```java
grades.length
```

### Size

Size er antallet af gemte elementer.

Eksempel:

```java
private int size;
```

Et array kan have ubrugte pladser.

Eksempel:

```text
Capacity = 10
Size = 3
```

Kun de første tre pladser indeholder meningsfulde værdier.

---

## 7. En GradeList-klasse

Eksempel:

```java
public class GradeList
{
  private int[] grades;
  private int size;

  public GradeList(int capacity)
  {
    grades = new int[capacity];
    size = 0;
  }
}
```

Klassen gemmer:

- selve arrayet
- det aktuelle antal tilføjede karakterer

---

## 8. Adgang til arrayelementer

Elementer tilgås ved hjælp af kantede parenteser.

Eksempel:

```java
return grades[index];
```

Eksempel på tildeling:

```java
grades[size] = grade;
```

Arrays giver direkte adgang via et indeks.

---

## 9. Tilføjelse af elementer

Eksempel:

```java
public void addGrade(int grade)
{
  grades[size] = grade;
  size++;
}
```

Det nye element placeres ved indekset `size`.

Derefter øges `size`.

Den næste ledige plads flyttes én position frem.

---

## 10. Kontrol af capacity

Før der tilføjes elementer, skal klassen sikre, at der er plads.

Eksempel:

```java
public boolean isFull()
{
  return size == grades.length;
}
```

Eksempel:

```java
if (isFull())
{
  throw new IllegalStateException(
      "Grade list is full");
}
```

Objektet beskytter sig selv mod ugyldige operationer.

---

## 11. Arrayets længde

Arrays gemmer deres capacity i feltet `length`.

Eksempel:

```java
grades.length
```

Vigtigt:

- `length` er ikke en metode
- der bruges ikke parenteser

Korrekt:

```java
grades.length
```

Forkert:

```java
grades.length()
```

---

## 12. Arrays med primitive datatyper

Arrays kan gemme primitive værdier.

Eksempler:

```java
int[] grades;
double[] temperatures;
char[] letters;
```

Arrays med primitive datatyper gemmer værdierne direkte.

---

## 13. Arrays med objekter

Arrays kan også gemme referencer til objekter.

Eksempler:

```java
String[] names;
Person[] persons;
```

Arrayet gemmer referencer.

Selve objekterne ligger et andet sted i hukommelsen.

---

## 14. Standardværdier i arrays

Elementerne i et array får automatisk standardværdier.

Eksempler:

| Type | Standardværdi |
|---|---|
| `int` | `0` |
| `double` | `0.0` |
| `boolean` | `false` |
| referencer | `null` |

Eksempel:

```java
new int[4]
```

opretter:

```text
0 0 0 0
```

---

## 15. Validering og arrays

Operationer på arrays bør validere indekser.

Eksempel:

```java
public int getGrade(int index)
{
  if (index < 0 || index >= size)
  {
    throw new IllegalArgumentException(
        "Index out of bounds: " + index);
  }

  return grades[index];
}
```

Objektet beskytter sig selv mod ulovlig adgang.

---

## 16. Logisk fjernelse af elementer

Nogle gange fjernes elementer logisk i stedet for fysisk.

Eksempel:

```java
public void removeLastGrade()
{
  if (size == 0)
  {
    throw new IllegalStateException(
        "No grades stored");
  }

  size--;
}
```

Selve arrayet ændres ikke.

Kun `size` ændres.

---

## 17. Tømning af en arraystruktur

Eksempel:

```java
public void clear()
{
  size = 0;
}
```

Arrayet eksisterer stadig.

Objektet betragter det blot som tomt.

---

## 18. Arrays og responsibility

Arrayet er en implementeringsdetalje.

Andre klasser bør ikke manipulere arrayet direkte.

Godt design:

```java
gradeList.addGrade(12)
```

i stedet for at eksponere selve arrayet.

Klassen skal beskytte:

- indekser
- capacity
- invarianter

---

## 19. Typiske begynderfejl

Almindelige fejl:

1. At glemme at oprette arrayet med `new`.
2. At forveksle `size` og `length`.
3. At tilgå ugyldige indekser.
4. At glemme, at indekser starter ved `0`.
5. At bruge `length()` i stedet for `length`.
6. At glemme at opdatere `size`.
7. At tilgå ubrugte pladser i arrayet.

---

## Opsummering

Session 7 introducerer arrays som samlinger med fast størrelse.

Vigtige idéer omfatter:

- arrays gemmer flere værdier
- arrays har en fast længde
- indekser starter ved `0`
- capacity og size er to forskellige begreber
- arrays kan gemme primitive værdier eller objektreferencer
- arrays kræver validering og kontrol af grænser
- arraystrukturen bør være encapsulated (indkapslet) inde i klassen

Arrays danner et vigtigt grundlag for det videre arbejde med løkker, dynamiske datastrukturer og samlinger.
