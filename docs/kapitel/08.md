# Kapitel 8 – Løkker

## 1. Introduktion

Session 8 introducerer løkker.

Løkker gør det muligt for programmer at gentage operationer.

Fokus er på:

- gennemløb af arrays
- `for`-løkker
- enhanced `for`-løkker
- `while`-løkker
- `do-while`-løkker
- gennemløb af arrays
- flytning af arrayelementer

Løkker er uundværlige, når man arbejder med samlinger af data.

---

## 2. Hvorfor løkker?

Uden løkker bliver gentagne operationer hurtigt ineffektive.

Mindre god løsning:

```java
sum += grades[0];
sum += grades[1];
sum += grades[2];
```

Bedre løsning:

```java
for (int i = 0; i < size; i++)
{
  sum += grades[i];
}
```

Løkker gør det muligt at gentage den samme operation systematisk.

---

## 3. `for`-løkken

`for`-løkken bruges typisk, når antallet af gentagelser er kendt.

Eksempel:

```java
for (int i = 0; i < size; i++)
{
  sum += grades[i];
}
```

En `for`-løkke består af:

- initialisering
- betingelse
- opdatering

Eksempel:

```java
for (int i = 0; i < size; i++)
```

---

## 4. Løkkevariabler

Løkkevariablen repræsenterer ofte et indeks.

Eksempel:

```java
int i
```

Løkkevariablen ændres ved hver gennemløb.

Eksempel:

```text
0 → 1 → 2 → 3
```

Indekser bruges ofte ved gennemløb af arrays.

---

## 5. Gennemløb af arrays

At gennemløbe et array betyder at besøge elementerne ét ad gangen.

Eksempel:

```java
for (int i = 0; i < size; i++)
{
  System.out.println(grades[i]);
}
```

Normalt bør løkken kun behandle de elementer, der faktisk er tilføjet.

Derfor er:

```java
i < size
```

ofte korrekt.

Ikke:

```java
i < grades.length
```

hvis arrayet indeholder ubrugte pladser.

---

## 6. Beregninger med løkker

Løkker bruges ofte til beregninger.

Eksempel:

```java
public int sumOfGrades()
{
  int sum = 0;

  for (int i = 0; i < size; i++)
  {
    sum += grades[i];
  }

  return sum;
}
```

Løkken opsummerer værdierne trin for trin.

---

## 7. Søgning med løkker

Løkker kan bruges til at søge efter bestemte værdier.

Eksempel:

```java
public boolean anyFailedGrades()
{
  for (int i = 0; i < size; i++)
  {
    if (grades[i] <= 0)
    {
      return true;
    }
  }

  return false;
}
```

Løkken undersøger hvert element.

---

## 8. Find den mindste værdi

Løkker kan bruges til at sammenligne værdier.

Eksempel:

```java
public int getMinimumGrade()
{
  int min = grades[0];

  for (int i = 1; i < size; i++)
  {
    if (grades[i] < min)
    {
      min = grades[i];
    }
  }

  return min;
}
```

Vigtig idé:

- start med en begyndelsesværdi
- opdatér den, når der findes en mindre værdi

---

## 9. Enhanced `for`-løkken

Den enhanced `for`-løkke gør gennemløb enklere.

Eksempel:

```java
for (int grade : grades)  // gennemløber alle elementer i arrayet
{
  sum += grade;
}
```

> Bemærk: Dette fungerer kun for arrays, hvis arrayet er fyldt.

Fordele:

- enklere syntaks
- lettere at læse
- intet eksplicit indeks er nødvendigt

Efter Session 8:

- brug enhanced `for`-løkker, når indekset ikke er nødvendigt
- brug indeksbaserede `for`-løkker, når indekset er nødvendigt

---

## 10. Begrænsninger ved enhanced `for`-løkker

Enhanced `for`-løkker kan ikke uden videre:

- tilgå indekser
- ændre arrayets struktur
- flytte elementer

Eksempel, hvor en indeksbaseret løkke er nødvendig:

```java
for (int i = index; i < size - 1; i++)
{
  grades[i] = grades[i + 1];
}
```

---

## 11. `while`-løkken

En `while`-løkke gentager så længe en betingelse er sand.

Eksempel:

```java
while (seconds > 0)
{
  tick();
}
```

Betingelsen kontrolleres før hver gennemløb.

En `while`-løkke kan derfor blive udført nul gange.

---

## 12. `do-while`-løkken

En `do-while`-løkke udføres mindst én gang.

Eksempel:

```java
do
{
  goOneFloorUp();
}
while (currentFloor < floor);
```

Betingelsen kontrolleres efter hver gennemløb.

---

## 13. Oversigt over løkketyper

### `for`-løkke

Bruges når antallet af gentagelser er kendt.

Eksempel:

```java
for (int i = 0; i < size; i++)
```

### Enhanced `for`-løkke

Bruges til enkle gennemløb. For arrays, når arrayet er fyldt, eller når den kombineres med en ekstra betingelse.

Eksempel:

```java
for (int grade : grades)
```

### `while`-løkke

Bruges når gentagelsen afhænger af en betingelse.

Eksempel:

```java
while (seconds > 0)
```

### `do-while`-løkke

Bruges når løkken skal udføres mindst én gang.

Eksempel:

```java
do { ... } while (...)
```

---

## 14. Fjernelse af elementer fra arrays

Fjernelse af et element kræver, at de efterfølgende elementer flyttes.

Eksempel:

```java
public void removeGrade(int index)
{
  for (int i = index; i < size - 1; i++)
  {
    grades[i] = grades[i + 1];
  }

  size--;
}
```

Elementerne kopieres mod venstre.

Hullet forsvinder.

---

## 15. Indsættelse af elementer ved et indeks

Indsættelse af elementer kræver også flytning.

Eksempel:

```java
public void addGrade(int index, int grade)
{
  for (int i = size; i > index; i--)
  {
    grades[i] = grades[i - 1];
  }

  grades[index] = grade;
  size++;
}
```

Elementerne kopieres mod højre.

Vigtigt:

- flytning kræver ofte, at man gennemløber baglæns

---

## 16. Arrays med variabel størrelse

Arrays har en fast længde.

Når capacity er opbrugt, kan der oprettes et større array.

Eksempel:

```java
private void doubleTheArrayLength()
{
  int[] newArray = new int[grades.length * 2];

  for (int i = 0; i < size; i++)
  {
    newArray[i] = grades[i];
  }

  grades = newArray;
}
```

De gamle værdier kopieres over i det nye array.

---

## 17. Løkker og responsibility

Løkker hører ofte hjemme i klasser, der repræsenterer samlinger.

Eksempel:

```java
gradeList.sumOfGrades()
```

i stedet for at eksponere arrayet.

Klassen bør have responsibility for:

- gennemløb
- søgning
- beregninger
- flytning af elementer

---

## 18. Test af løkkelogik

Metoder, der anvender løkker, bør testes grundigt.

Eksempel:

```java
@Test void minimumGrade()
{
  GradeList list = new GradeList(4);

  list.addGrade(12);
  list.addGrade(7);
  list.addGrade(10);

  assertEquals(7, list.getMinimumGrade());
}
```

Tests bør omfatte:

- tomme datastrukturer
- ét element
- flere elementer
- grænseindekser

---

## 19. Typiske begynderfejl

Almindelige fejl:

1. Off-by-one-fejl.
2. At bruge `<=` i stedet for `<`.
3. At glemme at opdatere løkkevariablen.
4. At gennemløbe ubrugte pladser i arrayet.
5. At glemme at øge eller mindske `size`.
6. At gennemløbe i den forkerte retning ved flytning af elementer.
7. Uendelige løkker.

## Opsummering

Session 8 introducerer løkker og gennemløb af arrays.

Vigtige idéer omfatter:

- løkker gentager operationer
- indeksbaserede `for`-løkker fungerer godt sammen med arrays
- enhanced `for`-løkker gør gennemløb enklere
- `while`- og `do-while`-løkker understøtter betingede gentagelser
- løkker kan beregne, søge og flytte data
- arrays kræver ofte flytning af elementer ved indsættelse og fjernelse
- arrays med variabel størrelse kræver kopiering af elementer

Løkker er en grundlæggende del af arbejdet med samlinger og datastrukturer.
