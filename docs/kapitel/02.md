# Kapitel 2 – String, referencer og null

I Session 2 flyttes fokus til:

Forståelse af referencer er et af de vigtigste begreber inden for objektorienteret programmering.

---

## 2. String er en klasse

`String` er ikke en primitiv datatype.

`String` er en klasse.

Eksempel:

```java
String name = "Ada";
```

Variablen indeholder ikke selve teksten.

Variablen indeholder en reference til et `String`-objekt.

Strings stiller metoder til rådighed.

Eksempel:

```java
String name = "Ada Lovelace";
int length = name.length();
```

---

## 3. Sammenkædning af Strings

Strings kan sammenkædes ved hjælp af operatoren `+`.

Eksempel:

```java
public String getFullName()
{
  return firstName + " " + lastName;
}
```

Eksempel på test:

```java
@Test void fullNameIsCombinedCorrectly()
{
  Name name = new Name("Ada", "Lovelace");
  assertEquals("Ada Lovelace", name.getFullName());
}
```

---

## 4. Referencer

Objektvariabler gemmer referencer.

Eksempel:

```java
Name n1 = new Name("Ada", "Lovelace");
Name n2 = new Name("Ada", "Lovelace");
Name n3 = n2;
```

Vigtigt:

- `n1` og `n2` refererer til forskellige objekter.
- `n2` og `n3` refererer til det samme objekt.

En reference fortæller programmet, hvor objektet befinder sig.

---

## 5. Værdien null

En referencevariabel kan indeholde `null`.

`null` betyder:

- at variablen ikke refererer til et objekt
- at der ikke findes noget objekt

Eksempel:

```java
Name name = null;
```

Hvis man kalder en metode på `null`, kastes en exception.

Eksempel:

```java
Name name = null;
name.getFullName();
```

Dette medfører en `NullPointerException`.
