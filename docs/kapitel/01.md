# Kapitel 1 – Hvad er et objekt?

## 1. Introduktion

Det primære mål med objektorienteret programmering er at modellere begreber fra et problemdomæne som softwareobjekter.

I PRO1 er fokus ikke først og fremmest på at lære Java-syntaks, men på at lære at tænke i:

- objects (objekter)
- responsibilities (ansvar)
- state (tilstand)
- behavior (adfærd)

Et objekt repræsenterer et begreb, som:

- gemmer information
- udfører operationer
- samarbejder med andre objekter

---

## 2. Objekter i den virkelige verden og i software

Objekter i den virkelige verden:

- har en tilstand
- kan udføre adfærd
- kan påvirke andre objekter

Softwareobjekter fungerer på samme måde.

Eksempel:

```java
Counter counter = new Counter();
counter.increment();
```

Et `Counter`-object gemmer en værdi og kan øge den.

Objektet husker sin egen værdi internt.

---

## 3. Variabler og objekter

En variabel kan gemme en primitiv værdi:

```java
int number = 5;
```

En variabel kan også gemme en reference til et objekt:

```java
Temperature temp = new Temperature(20.0);
```

Vigtigt:

- `temp` er en variabel
- `Temperature`-objektet oprettes med `new`

Variablen refererer til objektet.

---

## 4. Klasser som modeller

En klasse beskriver:

- hvilke data objektet gemmer
- hvilke operationer objekter kan udføre

Eksempel:

```java
public class Temperature
{
  private double celsius;

  public Temperature(double celsius)
  {
    this.celsius = celsius;
  }

  public double getCelsius()
  {
    return celsius;
  }

  public double getKelvin()
  {
    return celsius + 273.15;
  }
}
```

Klassen modellerer begrebet temperatur.

---

## 5. State og behavior

Et objekts tilstand gemmes i instansvariabler (fields).

Eksempel:

```java
private double celsius;
```

Behavior implementeres ved hjælp af metoder.

Eksempel:

```java
public double getKelvin()
{
  return celsius + 273.15;
}
```

Objektet har responsibility (ansvar) for at udføre operationer på sine egne data.

---

## 6. Konstruktører

En konstruktør initialiserer et nyoprettet objekt.

Eksempel:

```java
public Temperature(double celsius)
{
  this.celsius = celsius;
}
```

Konstruktøren sikrer, at objektet starter med en gyldig initial state.

Objekter oprettes ved hjælp af `new`:

```java
Temperature temp = new Temperature(20.0);
```

---

## 7. Metoder

Metoder definerer de operationer, et objekt kan udføre.

Eksempler:

- ændre state
- returnere information
- beregne værdier

```java
public int getValue()
{
  return value;
}
```

```java
public void increment()
{
  value++;
}
```

Nogle metoder returnerer værdier.

Nogle metoder ændrer objektets state.

---

## 8. Boolean-metoder

En metode kan returnere en boolean-værdi.

Eksempel:

```java
public boolean isZero()
{
  return value == 0;
}
```

Boolean-metoder besvarer typisk spørgsmål om objektet.

---

## 9. Test af objekter med JUnit

Objekter testes ved at:

1. oprette objekter
2. kalde metoder
3. kontrollere resultater

Eksempel:

```java
@Test void incrementOnceReturns1()
{
  Counter counter = new Counter();
  counter.increment();

  assertEquals(1, counter.getValue());
}
```

Test fokuserer på objektets observerbare behavior.

---

## 10. Primitive typer anvendt i session 1

I session 1 anvendes primært:

- `int`
- `double`
- `boolean`

Eksempler:

```java
private int value;
private double celsius;
```

---

## 11. Typiske begynderfejl

Almindelige fejl:

1. At forveksle et objekt med en variabel.
2. At glemme at oprette objektet med `new`.
3. At placere logik uden for objektet.
4. At glemme, at objekter gemmer state.

## Opsummering

Et objekt:

- modellerer et begreb
- gemmer state
- stiller behavior til rådighed
- oprettes ud fra en klasse
- har responsibility for sine egne operationer

Objektorienteret programmering handler om at designe meningsfulde objekter og tildele responsibilities korrekt.
