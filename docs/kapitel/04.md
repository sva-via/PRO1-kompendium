# Kapitel 4 – Selektioner

## 1. Introduktion

Session 4 introducerer selektionsstrukturer i Java.

Selektionsstrukturer gør det muligt for et program at træffe beslutninger.

Fokus er på:

- `if`
- `if-else`
- `else-if`
- `switch`
- relationelle operatorer
- logiske operatorer

Selektionsstrukturer anvendes, når et objekts behavior (adfærd) afhænger af betingelser.

---

## 2. Kontrolstrukturer i Java

Java-programmer anvender tre hovedtyper af kontrolstrukturer:

### Sekvens

Sætninger udføres én efter én.

### Selektion

Programmet vælger mellem forskellige alternativer.

Eksempler:

```java
if
if-else
switch
```

### Gentagelse

Programmet gentager sætninger.

Løkker introduceres senere i kurset.

---

## 3. if-sætningen

En `if`-sætning udfører kun kode, hvis en betingelse er sand.

Eksempel:

```java
public String status()
{
  String status = "Adult";

  if (getAge() < 18)
  {
    status = "Child";
  }

  return status;
}
```

Betingelsen skal være et boolesk udtryk.

---

## 4. if-else-sætningen

`if-else` vælger mellem to alternativer.

Eksempel:

```java
public String status()
{
  if (getAge() < 18)
  {
    return "Child";
  }
  else
  {
    return "Adult";
  }
}
```

Den ene gren udføres, hvis betingelsen er sand.

Den anden gren udføres, hvis betingelsen er falsk.

---

## 5. Kædede else-if-sætninger

`else-if` håndterer flere alternativer.

Eksempel:

```java
public String status()
{
  if (getAge() < 13)
  {
    return "Child";
  }
  else if (getAge() < 20)
  {
    return "Teenager";
  }
  else
  {
    return "Adult";
  }
}
```

Betingelserne kontrolleres fra toppen og ned.

Den første betingelse, der er sand, udføres.

---

## 6. Relationelle operatorer

Relationelle operatorer sammenligner værdier.

| Operator | Betydning |
|---|---|
| `>` | større end |
| `<` | mindre end |
| `>=` | større end eller lig med |
| `<=` | mindre end eller lig med |
| `==` | lig med |
| `!=` | ikke lig med |

Eksempel:

```java
if (x >= 10)
{
  // ...
}
```

Relationelle operatorer returnerer booleske værdier.

---

## 7. Logiske operatorer

Logiske operatorer kombinerer booleske udtryk.

| Operator | Betydning |
|---|---|
| `&&` | OG |
| `||` | ELLER |
| `!` | IKKE |

Eksempel:

```java
if (x >= 10 && x < 100)
{
  // x er et tocifret tal
}
```

Eksempel:

```java
if (!isTwoDigit)
{
  // ...
}
```

Logiske operatorer er vigtige, når behavior afhænger af flere betingelser.

---

## 8. Booleske udtryk

Et boolesk udtryk evalueres til enten:

- `true`
- `false`

Eksempler:

```java
x > 10
```

```java
age < 18
```

```java
email != null
```

Booleske udtryk er centrale i selektionsstrukturer.

---

## 9. Sammenligning af primitive datatyper

Primitive værdier sammenlignes ved hjælp af relationelle operatorer.

Eksempel:

```java
if (x == 7)
{
  // ...
}
```

Eksempel:

```java
if (x != 7)
{
  // ...
}
```

Dette fungerer korrekt for primitive datatyper som:

- `int`
- `double`
- `char`
- `boolean`

---

## 10. Sammenligning af Strings

Strings er objekter.

Brug ikke `==` til at sammenligne Strings.

Undgå:

```java
if (s == "Bob")
{
  // forkert løsning
}
```

Brug i stedet `equals()`.

Korrekt:

```java
if (s.equals("Bob"))
{
  // korrekt løsning
}
```

Eksempel:

```java
if (!s.equals("Bob"))   // s er ikke lig med "Bob"
{
  // ...
}
```

Efter Session 2 og Session 4 bør `equals()` altid bruges ved sammenligning af Strings.

---

## 11. Kontrol af null

En reference kan være `null`.

Selektionsstrukturer bruges ofte til at kontrollere for `null`.

Eksempel:

```java
if (email != null)
{
  s += ", email=" + email;
}
else
{
  s += ", no email";
}
```

Dette forhindrer, at man bruger eller kalder metoder på `null`-referencer.

---

## 12. switch-sætninger

En `switch`-sætning håndterer flere alternativer.

Eksempel:

```java
public String getDayOfWeek()
{
  switch(day)
  {
    case 1:
      return "Monday";
    case 2:
      return "Tuesday";
    case 3:
      return "Wednesday";
    default:
      return "Unknown";
  }
}
```

`switch` er nyttig, når der skal vælges mellem mange faste værdier.

---

## 13. toString() og selektioner

Selektionsstrukturer bruges ofte i `toString()`-metoder.

Eksempel:

```java
public String toString()
{
  String s = name + ", semester=" + semester;

  if (email != null)
  {
    s += ", email=" + email;
  }
  else
  {
    s += ", no email";
  }

  return s;
}
```

Objektets output ændrer sig afhængigt af dets state.

---

## 14. Responsibility og selektioner

Selektionslogik bør normalt placeres inde i objektet.

Eksempel:

God løsning:

```java
person.isAdult()
```

Mindre god løsning:

```java
person.getAge() >= 18
```

Objektet bør have responsibility for beslutninger, der bygger på dets egne data.

---

## 15. Test af selektionslogik

Selektionslogik bør testes grundigt.

Eksempel:

```java
@Test void childStatus()
{
  Person p = new Person("Bob", 10);

  assertEquals("Child", p.status());
}
```

Vigtige testtilfælde omfatter:

- normale tilfælde
- grænseværdier
- alternative grene

---

## 16. Typiske begynderfejl

Almindelige fejl:

1. At bruge `=` i stedet for `==`.
2. At bruge `==` til Strings.
3. At glemme krøllede parenteser `{}`.
4. At skrive overlappende betingelser.
5. At skrive umulige betingelser.
6. At glemme `else`.
7. At kalde metoder på `null`.
